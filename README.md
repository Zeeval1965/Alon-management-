# מעקב ביצוע – הלל הזקן 14 (גרסת פיתוח)

## הפעלה
```
pip install flask openpyxl pdfplumber werkzeug
export APP_SECRET="<ערך אקראי ארוך>"       # חובה בסביבה אמיתית
python app.py set-password <דוא"ל> <סיסמה>  # יצירת סיסמה למשתמש
python app.py                               # הרצה על http://localhost:5055
python app.py run-reminders                 # תזמון: תזכורות לכל האתרים (בתור היוצא)
python -m unittest discover -s tests -v     # בדיקות
```

## משתני סביבה
- `APP_DB` – נתיב קובץ ה-SQLite (ברירת מחדל: `app.db` בתיקיית האפליקציה).
- `APP_DEV_MODE` – `1` (ברירת מחדל): כל הודעה יוצאת מופנית לבעל הפרויקט. `0`: שליחה לנמענים האמיתיים.
- `APP_DEV_EMAIL` – כתובת הבעלים לקבלת הודעות בשלב הפיתוח.
- `APP_DEV_MOBILE` – נייד לחיבור WhatsApp בעתיד.

## מה יש בגרסה
- כניסה עם דוא"ל וסיסמה, והרשאות לפי תפקיד באתר (טבלה ב-`app.py`, `ROLE_READ` ו-`ROLE_WRITE`).
- ייבוא אנשי קשר, פרוטוקולי ביצוע ושבועיים (PDF), סקירה ופרסום.
- משימות: עדיפות, סטטוס "בוצע", היסטוריית יעדים, הצעת אחראים לאישור המפקח.
- תור מנהל מערכת לשורות שלא זוהו בוודאות.
- החלטות לפי נושא (ידני ומתוך פרוטוקולים).
- דוחות פיקוח עם שמות התמונות.
- תוכניות וגרסאות להורדה.
- התקדמות לפי קומה ושלב, עם הגדרת קומות ושלבים לכל אתר.

## מה עדיין לא מחובר
- שליחה בפועל: דוא"ל, WhatsApp ו-SMS. ההודעות נשמרות בתור היוצא בלבד.
- Google Drive לתוכניות.
- שחזור סיסמה וחסימה לאחר ניסיונות כושלים.
- תרשים בניין ויזואלי. כרגע ההתקדמות מוצגת כטבלה.
- שלבי העבודה לאתר אינם סופיים: ברירת המחדל מתוך האיפיון, וצריך לאשר.
